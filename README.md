## :mag_right: 프로젝트 개요

- 부경대학교 컴퓨터공학전공 캡스톤디자인 2인 프로젝트
- 진행 기간 : 2025.04 ~ 2025.11
- 국내 여행 계획 보조 웹 서비스

## :bulb: 핵심 기능

### :calendar: 네이버 지도 API를 활용한 편리하고 직관적인 여행 계획
<ul> - 일정에 따른 장소 및 경로를 지도 상에 표시 </ul>
<ul> - 장소별 비용 입력을 통한 예산 관리 </ul>

### :books: TourAPI 4.3을 활용한 국내 관광 데이터 제공
<ul> - 다양한 국내 여행 정보를 지역별, 카테고리별로 검색하여 열람 가능 </ul>
<ul> - 실시간 데이터 업데이트를 통한 최신 정보 제공 </ul>

### :speaker: 사용자 간 원활한 소통을 위한 커뮤니티 기능 지원
<ul> - 실시간 채팅 및 지도 공유를 통한 동반 여행 계획 </ul>
<ul> - 관광지 별 리뷰 작성 및 평가 확인 </ul>
<ul> - 일정 공유를 통한 추천 일정 탐색 </ul>
